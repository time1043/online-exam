## Auth

- 或许不应该开放注册，只能允许登陆
- Admin 根据名单，批量生成账号

- Student 允许注册
- Student 注册后，进入主页，绑定指定课程

## Admin

- 管理 Teacher/Student 账号

## Subject

1. Teacher 创建 Subject
2. Student 通过邀请码，接受 Subject

## Exam

1. Teacher 组卷，设置好判题策略（手动判题、自动判题）
2. Student 考试，考完后提交
3. 客观题自动判题，出示客观题分数
4. 主观题完成判题，出示主观题分数和总分
